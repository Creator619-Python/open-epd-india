About this database

Data source
All EPDs published by Indian manufacturers on the International EPD System (environdec.com), collected in June 2026. EPD data is the intellectual property of respective manufacturers and programme operators.
GWP extraction
GWP A1-A3 values were extracted from 388 EPD PDFs using AI (Google Gemini 2.5 Flash + Llama 3.3 70B via Groq). 384 values extracted. 383 rated HIGH confidence by the model. Always verify against the source EPD before formal use.
